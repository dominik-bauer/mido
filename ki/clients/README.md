# Clients

- `web/` – Dashboard im Heimnetz (F-16): Prompt, gestreamte Antworten, Artefakte speichern.
  Eigenbau ohne Framework und ohne externe Dateien, weil Open WebUI für einen
  Raspberry Pi 3 zu schwer ist. Wird vom Assistent-Dienst ausgeliefert.
- `cli-rust/` – Kommandozeilen-Client in Rust (F-19)
- `esp32/` – Anzeige/Taster/Mikrofon, z. B. eInk-Kalenderstation (F-17, UC-5)
